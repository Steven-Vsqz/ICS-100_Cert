# 🚨 FEMA National Incident Management System (NIMS): ICS-100

---

## 📌 Overview

I completed the **ICS-100: Introduction to the Incident Command System** as part of FEMA’s National Incident Management System (NIMS) training. This course provided a strong foundation in emergency response coordination and command structure. Key takeaways include:

- 🧭 Understanding the Incident Command System (ICS) framework  
- 🧑‍✈️ Roles and responsibilities of incident personnel (e.g., Incident Commander, Command Staff)  
- 🧩 Core principles of NIMS including flexibility, standardization, and coordination  
- ⚙️ Real-world application of emergency management strategies

This training enhanced my ability to contribute effectively during emergency operations and collaborate across teams and jurisdictions.
